General

Server
Shared settings
Everything on this page is stored on the server, so every device and every phone Shortcut uses it. Server URL, API token and the screenshot folder are set per device in the Obsidian plugin.
Sign out
Forget the API token in this browser.

Capture

Screenshot style
Full page scrolls the whole page, banner keeps the first screen, or save no screenshot at all.
Sites with banner screenshots
One site per line. These sites and their subdomains get only the first screen, whatever the style above.
Sites without screenshots
One site per line. These sites and their subdomains keep the link and text but no screenshot. Blocked pages never get one.

Template

One per line: a URL prefix like https://github.com/ or a regex like /youtube\.com\/watch/. The first template that matches is used; otherwise the default (top) template.
Properties
The page URL and capture id are always saved, even if you remove them here.
