General

Server
Shared settings
Everything on this page is stored on the server, so every device and every phone Shortcut uses it. Server URL, API token and the screenshot folder are set per device in the Obsidian plugin.
Hide capture ID
Leave the capture_id property out of new notes. Obsidian then remembers which captures it already wrote, and a capture of a page that's already saved is still skipped.
Save from your browser
Drag a button to your bookmarks bar, then click it on any page to save that page, like the phone Shortcut. It works in this browser while you're signed in here, and Obsidian can be closed.

Properties

Property types are shared by every template, as in Obsidian. Changing a type here, or in a template, changes it everywhere. A new property in a template takes its type from this list.

Variables

Use these in a template's note name, properties and note content. Click one to copy it. Filters go inside the braces, e.g. {{title|kebab}}, and can be chained.

Page

From the captured page.

{{title}}Page title.
{{url}}Link saved for the bookmark: the page's canonical URL when it's on the same site.
{{description}}Page description or summary.
{{author}}Author, when the page names one.
{{published}}Publish date, when the page has one.
{{site}}Site name, e.g. Hugging Face.
{{domain}}Domain without www, e.g. huggingface.co.
{{image}}Main image URL (the social preview image).
{{favicon}}Site icon URL.
{{content}}The readable page text as Markdown.
{{words}}Word count of the readable text.
{{language}}Page language, e.g. en.

Capture

About this bookmark.

{{date}}When the page was captured, in the server's time zone (TZ). Format it with |date:"YYYY-MM-DD".
{{capture_id}}The capture's id; always saved so a capture is never written twice.

Screenshots and PDF

Each is the saved file's vault path. Wrap it to show the image, ![[{{screenshot_page}}]], or to link it, [[{{screenshot_page}}]], in the note content or a property. A file is made only when a template uses it, and is empty for a blocked page; the brackets around an empty one are removed.

{{screenshot_page}}The whole page, e.g. Bookmarks/assets/note.jpg.
{{screenshot_banner}}The first screen (1280×800), note-banner.jpg.
{{screenshot_mobile}}The first screen at phone width (390×844), note-mobile.jpg.
{{screenshot_article}}Just the main content block, without navigation or sidebars, note-article.jpg. Empty when the page has no article or main element.
{{screenshot_thumbnail}}A small first screen (480×300) for covers in Bases or card views, note-thumbnail.jpg.
{{pdf_page}}A PDF of the page with selectable text, note.pdf.

Add _dark to any screenshot for the site's dark mode, e.g. {{screenshot_page_dark}} (note-dark.jpg) or {{screenshot_mobile_dark}} (note-mobile-dark.jpg). Sites without a dark mode look the same.

Templates saved or imported with the older {{screenshot}}, {{screenshot_link}} and {{screenshot_embed}} are rewritten to these.

Schema and meta

Read from the page's schema.org data and meta tags, as in Web Clipper.

{{schema:@Type:path}}A value from schema.org data of that type, e.g. {{schema:@Recipe:name}} or {{schema:@BreadcrumbList:itemListElement[2].name}}. [*] takes every item.
{{schema:path}}The same, from any schema.org object on the page.
{{meta:name:author}}A <meta name=…> tag.
{{meta:property:og:title}}A <meta property=…> tag.

Selectors

Read from the page as the server's browser rendered it.

{{selector:h1}}Text of the elements matching a CSS selector.
{{selector:img.hero?src}}An attribute of the matching elements.
{{selectorHtml:article}}HTML of the matching elements.

Filters and logic

Notes are rendered by Web Clipper's own template engine, so every Web Clipper filter and logic tag works.

|kebabMy Page Title becomes my-page-title.
|safe_nameRemoves characters not allowed in file names.
|date:"YYYY-MM-DD"Formats a date.
|split:","|wikilink|joinTurns "a, b" into "[[a]], [[b]]".
{% if author %}…{% endif %}Includes text only when a value is set.

Not supported yet

Prompt variables like {{"summary of page"}} come out empty (planned for the AI stage), and so do {{highlights}} and {{selection}}, which need you in the browser.

Template

One per line: a URL prefix like https://github.com/, a regex like /youtube\.com\/watch/, or a schema.org type like schema:@Recipe. The first template that matches is used; otherwise the default (top) template.
